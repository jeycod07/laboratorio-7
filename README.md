# Laboratorio 7 - Recursividad

Sistema de analisis de entregas digitales desarrollado en C#.

## Funcionalidades

- Sumatoria recursiva de puntajes.
- Busqueda de estudiantes.
- Conteo de archivos por palabra clave.
- Factorial y potencia recursiva.
- Comparacion entre recursividad e iteracion.
- Validacion de entradas.
- Pruebas con arreglos vacios.

## Tecnologias

- C#
- .NET 10
- Visual Studio Code
- GitHub

## Ejecucion

dotnet run --project laboratorio
